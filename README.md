# Namitha Dsouza — Technical Portfolio

Next.js + Tailwind CSS portfolio prepared for deployment.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

1. Create a new GitHub repository (for example, `portfolio`).
2. Upload/push all files from this folder to that repository.
3. Sign in to Vercel with GitHub.
4. Choose **Add New → Project** and import the repository.
5. Vercel should detect **Next.js** automatically. Keep the default settings and deploy.
